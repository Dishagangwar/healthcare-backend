Patient and doctor records, with an API behind them.

Built with Django and PostgreSQL, authenticated with JWT. Every record belongs to whoever created it — enforced in the queryset, not just the permission check.

Create an account Log in

A workspace of your own

Sign up and the patients and assignments you add are visible only to you. You can edit and delete them freely — nobody else can see them.

A shared directory

Doctors are readable by every account, so the entries already on file can be assigned straight away. Only whoever added one may change it.

The same rules through the API

Send your email and password to POST /api/auth/login/, then pass the access token as a bearer token. Another user's record answers 404 rather than 403, so the API never confirms that it exists.
